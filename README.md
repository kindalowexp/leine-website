# Leinecode Website (GitHub Pages)

Dieser Ordner ist die fertige Live-Version. Alle Schriften und Bilder liegen lokal
(fonts/, img/), die Seite lädt nichts von Google oder anderen fremden Servern.

## Kostenlos veröffentlichen
1. Auf github.com ein neues Repository anlegen, z. B. `leinecode-website` (öffentlich).
2. Den kompletten Inhalt dieses Ordners hochladen, inklusive der Ordner `fonts` und `img`
   ("Add file" > "Upload files", Ordner per Drag-and-drop).
3. Settings > Pages > Source: "Deploy from a branch", Branch `main`, Ordner `/ (root)`.
4. Nach 1–2 Minuten ist die Seite unter https://<github-name>.github.io/leinecode-website/ erreichbar.
